# VELTRIX Monitor 性能核对（2026-10-06）

目标：使用 Tkinter 和现有依赖，保持轻量常驻，不引入网页引擎、曲线绘制或持续动画。默认采样 2 秒、记录 5 秒，最快 0.5 秒。隐藏窗口停止表格/摘要绘制，继续采集和告警。

## UI 对比

同一台 Windows 机器、Python 3.13。300 个固定模拟温度传感器，每个场景调用刷新 150 次；使用原 `41f4f00` 的窗口代码作基线。托盘和硬件采集均不参与这一计时。

| 场景 | 原版 ms/次 | 新版 ms/次 | 原版表格写入/次 | 新版表格写入/次 |
|---|---:|---:|---:|---:|
| 采样序号未变 | 2.8437 | 0.0059 | 1500 | 0 |
| 新采样、数值相同 | 3.4137 | 0.9518 | 1500 | 0 |
| 窗口隐藏 | 3.6283 | 0.0050 | 1500 | 0 |

新版相同数值刷新减少约 72% 的 UI 处理时间。变化的数值仍会写入；隐藏后恢复窗口会呈现最新快照。温度摘要和搜索共用现有采集结果。

复测：`python tools/benchmark_ui.py`。`--baseline FILE` 可对比旧窗口模块。

## 真实采集

普通用户权限，默认 2 秒采样、5 秒记录，使用临时数据库。冷启动完成后计时 30 秒，得到 15 次采样、93 个读数。

- 进程 CPU 时间：0.3438 秒；约为单核 1.146%，24 个逻辑处理器整机口径约 0.0477%。
- 进程 RSS：158.8 MB，包含现有 Python/.NET 硬件读取库。
- 此项仅测采集进程，不包含窗口/托盘绘制；不代表管理员权限下更多硬件传感器的开销，也不承诺所有机器零性能影响。

复测：`python tools/benchmark_runtime.py --seconds 30`。不安装驱动、不提权，不读取或改写用户的监控数据库。

## 回归保护

离线 UI 测试覆盖旧高频配置钳制、后台告警、不重复绘表、窗口恢复、搜索、折叠与选择保持、真实供电温度与电压区分、单一刷新计时器、告警历史上限、托盘缓存和图标切换。原解析/分类/告警测试及真实硬件界面冒烟测试也通过。
